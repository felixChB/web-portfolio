Rising Weather

[About]

Rising Weather is an interactive media installation developed for my bachelor thesis. The goal was to examine the impression of abstract data-driven visuals on the audience in an interactive installation.

Through hand gestures in front of the visualisation the user can navigate along a timeline of weather data from the black forest. The visualisation reacts to the underlying data and gives the user an abstract image of the weather of this specific year. A Kinect was used to track the users hands for the navigation which should minimise the barrier for the user to interact with the installation.

It was shown and tested at the „Instandsetzung“ festival in Schwenningen in 2022.

[Tools]

Touchdesigner, Kinect, GLSL
