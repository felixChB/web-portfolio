# VR-Pong
VR-Pong

### Year

### Tags

### Tools
webXR, node.js, babylon.js, typescript

## Description
VR-Pong is a co-located multiplayer VR web-game which can be simply played with a XR-headset through the web-browser. It was the major part of my master thesis and was used to explore the possibilities of webXR to create co-located multiplayer VR experiences. In the game up to 4 players can play a 3D VR-version of the original Pong game against each other. The game was used to investigate the differences between web-based and native approaches and to look for possible limitations of this newer method. The project was first displayed at the „Südwest Messe“ in Villingen-Schwenningen in 2025 and is currently still playable at selected events.

# Rising Weather
Rising Weather

## Site-details
### Id
rising-weather

### Year
2022

### Tags
[installation, interactive, visualisation, data-driven]

### Tools
Touchdesigner, Kinect, GLSL

## Description
Rising Weather is an interactive media installation developed for my bachelor thesis. The goal was to examine the impression of abstract data-driven visuals on the audience in an interactive installation.
Through hand gestures in front of the visualisation the user can navigate along a timeline of weather data from the black forest. The visualisation reacts to the underlying data and gives the user an abstract image of the weather of this specific year.
A Kinect was used to track the users hands for the navigation which should minimise the barrier for the user to interact with the installation.
It was shown and tested at the „Instandsetzung“ festival in Schwenningen in 2022.

an interactive data-driven media installation

# Constructor
Constructor

### Id

### Year
2023

### Tags
[game-asset, 3D-modelling, texture-painting]

### Tools
Blender, Gimp

## Description
This 3D model is a modified version of a „Hyperion-Constructor“ from the game Borderlands 3 and the so called masterpiece of the subject „Digital Asset Creation“ during my bachelor study. The goal was to create a new 3D model which replicates the look and feel of a game of choice so that it will fit right into it. The concept of this model was a from bandits raided and reused old constructor robot, which now blends the style of the bandits with the original style of the robots company.
The model was fully modeled in blender and the textures where digitally hand-painted to create the ruff cartoon-style of the game.

### short Description
a hand-painted 3D-model of a modified Borderlands 3 Constructor-Character

# UI-verse
UI-verse

### Year

### Tags
[web-design, interactive, timeline]

### Tools
javascript, Adobe XD

## Description
UI-Verse is the outcome of the subject „Interface Design“ in my bachelor study. The task was to create a new interface under the theme „distance“. I came up with the idea of an interactive timeline which lets the user explore the origin and history of our universe. The project was implemented using web-technologies to be able to reach a big audience. It was designed to be displayed in a museum or other learn environments. The main challenge was to create a smooth navigation and a polished look for the timeline.

### short Description
an interactive timeline about the origin of the universe
