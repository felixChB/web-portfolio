## Description
VR-Pong ist ein co-located Multiplayer VR-Spiel, bei welchem bis zu vier Spieler in einer virtuellen Welt gegeneinander 3D-Pong spielen können. Das Besondere istm, dass die Spieler sich dafür in der echten Welt treffen und so ein neues Gefühl des gemeinsamen VR-Erlebens erfahren können. Das Projekt war Teil meiner Master-Thesis an der HFU. VR-Pong wurde fürs Web mit webXR entwickelt und ist so ohne Installation über den Browser spielbar. Aktuell wird das Spiel teils auf Messen für Besucher ausgestellt.

### short Description
a co-located Multiplayer VR Web-Game

# Rising Weather

### Id

### URL
/projects/rising-weather.html

### Folder
/rising-weather

### Tags
[installation, interactive, visualisation, data-driven]

## Description
Bei Rising Weather handelt es sich um eine interaktive Medieninstallation. Durch Gestensteuerung  können sich die Nutzer auf einem Zeitstrahl durch die Jahre bewegen. Die Installation stellt dabei das Wetter des jeweiligen Jahres abstrahiert dar. Für die Darstellung werden Temperaturdaten verwendet, welche die Visuals dynamisch verändern. Rising Weather entstand im Rahmen meiner Bachelor-Thesis an der HFU. Ziel war es die Rezeption von abtrakter datenbasierter Visualisierung in Form einer interaktiven Installation zu untersuchen.

### short Description
an interactive data-driven media installation
